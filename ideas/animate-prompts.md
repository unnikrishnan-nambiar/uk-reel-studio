# ANIMATE — 6 animation styles, one prompt each

Paste any prompt into Claude (claude.ai, the app or Claude Code). Change the text in [brackets] to your own topic.
Each one gives you a single HTML file that plays the animation in your browser. Screen-record it on your phone or laptop to use it in a reel.

---

## 1. /teardown — exploded view, every part labelled
```
Make a single self-contained HTML file: a 1080x1920 vertical animation on a dark background.
Show [a mechanical keyboard] in 3D at an isometric angle. Over 3 seconds, it slowly comes apart into its layers ([keycaps, switches, plate, circuit board, case]), stacked with even gaps.
As each layer separates, add a clean label on the right: number, part name, one short spec line in a monospace font.
Smooth easing, soft shadows, one orange accent colour. No libraries, plain HTML/CSS/JS.
```

## 2. /ink-wash — ink painting title card
```
Make a single self-contained HTML file: a 1080x1920 vertical animation in Chinese ink-wash painting style on warm off-white paper.
Layers of misty mountains fade in from far (pale) to near (dark), a red sun appears, three birds drift across, a tiny boat floats on calm water, a dark cliff on the right.
A vertical serif title writes itself letter by letter: "[THE RIVER KEEPS NO NAME]".
Very slow camera push-in. Calm, minimal, no libraries.
```

## 3. /stat-chart — big number, chart, one callout
```
Make a single self-contained HTML file: a 1080x1920 vertical fintech-style animation on near-black.
Top: a small brand line "[◆ LUMA PAY]" and the label "[Annualised payment volume]".
A huge number counts up from [$0.4B] to [$4.2B] while a line chart draws from [2019] to [2025]. The last part of the line turns orange after [the card launch].
Then a small badge "[▲ 220% since the card launched]" and one callout card "[MAR 2024 — Card launches — volume doubles in five months]" pop in.
Inter-style bold type, thin grid lines, no libraries.
```

## 4. /map-route — 3D city, route drawn live
```
Make a single self-contained HTML file using canvas: a 1080x1920 vertical animation of a light-grey isometric 3D city.
Blocks of white buildings rise in a wave, a light-blue river and a small green park sit between them.
A bright blue route draws itself along the streets from [Riverside Park] to [Central Station] while the camera gently follows it. A red pin drops at the end.
Finish with a white card at the bottom: "[14 min · 4.2 km · to the Studio]". Small rounded place labels. No libraries.
```

## 5. /headline — article push-in, line highlighted
```
Make a single self-contained HTML file: a 1080x1920 vertical animation.
A newspaper page drops onto a dark blurred desk and settles at a slight angle: masthead "[The Evening Ledger]", a red section tag, a big serif headline "[A regional retailer quietly moved its call centre to AI. Then margins doubled.]", a byline and a paragraph with a drop cap.
The camera slowly pushes in, then a lime highlighter sweeps across one key sentence: "[By September, support costs had fallen 58 percent…]".
Serif fonts for the paper, realistic shadow, no libraries.
```

## 6. /paper-desk — notes on a desk, marked up
```
Make a single self-contained HTML file: a 1080x1920 vertical animation on a green cutting mat with a fine grid.
A paper note with tape at the corners drops in: a small label "[FIG. 1 — RETENTION, FIRST 60 SECONDS]", a serif title "[Most viewers decide in the first three seconds]" and a line chart that draws itself.
A red hand-drawn circle appears around [the steep drop], an arrow, and red marker text "[THEY LEAVE HERE]".
A second note slides in from the side with a short paragraph and one sentence highlighted in yellow, plus a torn label "[THE HOOK]".
Slow push-in, no libraries.
```

---

**Tip:** if the first version looks plain, reply "make it more cinematic: slower easing, deeper shadows, more depth". To export it as a video, ask Claude to "add a record mode that plays once at 60fps", then screen-record it.
